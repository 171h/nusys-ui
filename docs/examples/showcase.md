# 综合体验

表单区域的“悬停图标与文字宽度”可调整选择框宽度，观察下拉图标不透明度、文字区域的双向过渡和多选标签折叠，并对照组合框与禁用状态。示例也可在 [单选框](../components/single-select#功能场景) 和 [多选框](../components/multi-select#功能场景) 专有页中操作。

布局区域的“标签页溢出与标题图标”可调整容器宽度、溢出方式、换行对齐、图标模式、面板风格与标题高度。缩小容器后，通过右侧 `...` 选择隐藏标签；组件标题链接进入 [Tabs 独立示例与设置说明](../components/tabs#溢出布局设置)。
