# 综合体验

表单区域的“悬停与焦点下的图标和文字宽度”可调整选择框宽度，观察下拉图标在悬停或获得焦点时显示、文字区域的双向过渡和多选标签折叠，并对照组合框与禁用状态。示例也可在 [单选框](../components/single-select#功能场景) 和 [多选框](../components/multi-select#功能场景) 专有页中操作。

布局区域的“标签页溢出与标题图标”可调整容器宽度、溢出方式、换行对齐、图标模式、面板风格与标题高度。缩小容器后，通过右侧 `...` 选择隐藏标签；组件标题链接进入 [Tabs 独立示例与设置说明](../components/tabs#溢出布局设置)。

布局区域的 Ribbon 示例集中排列，包含一体布局、[标签栏与内容面板分离布局](#demo-ribbon-separated)、菜单、响应式降级、图库、状态与国际化。拆分示例在标题栏左侧保留应用标识，两个滑块可独立
调整标签栏和功能面板宽度。可切换布局、折叠、操作混合子菜单，并查看事件次数。
配置与生命周期参见 [Ribbon 分离布局](../components/ribbon#标签栏与内容面板分离布局)。
